== Clashes — things that look local and are not

. *The required context is estate-wide, not ours.* `scan / gitleaks` is required
  by a ruleset in many repos. Any change to its producer must keep the job id
  `scan` and that exact context string. A rename here breaks branch protection
  in repos you are not looking at.
. *hypatia rewrites allow-lists.* The curated superset PUT widens
  `patterns_allowed`. A hand-narrowed list (a deliberate security posture) will
  be widened by the sweep, and #638 says something else narrows it back. Do not
  "fix" a repo by hand-editing a list the sweep owns — either change the
  superset file or inline the workflow.
. *cicd-suite's gates are shared.* `prove_args` is appended to the planted
  control crates as well as the consumer's. Asking cicd-suite for "just pass
  `--features creusot`" would break every consumer whose controls do not define
  that feature; the ask has to be *caller-crate-scoped arguments*, or nothing.
  This repo worked around it (contracts are a default feature); that workaround
  does not generalise, which is why the upstream ask is still open.
. *standards is a library, not a service to this repo.* The prompts above ask it
  for publication, data and a resolvability check — not for anything shaped
  around cicd-squabbler. If a change only helps this repo, it belongs here.
. *This repo is a tool other repos run.* Changing `chains` severity (moved =
  blocking, exit 4) and the 404 policy changes what consumers' CI does when
  they adopt v0.2.0. Neither is released yet, so now is the moment to write it
  down — after the release, it is a breaking change.
. *`rsr-template-repo` multiplies every decision.* A default that assumes Rust,
  or a required context the template cannot emit, is reproduced in every new
  repo. Prefer opt-in.
. *Sonar/CodeRabbit/Codex are third-party reviewers with write access.* Several
  of their suggestions in #140 were right; a few conflicted (the overflow fix
  landed twice from two directions). Reconcile before acting, and never let a
  bot's suggestion be applied unreviewed to a proof obligation.
