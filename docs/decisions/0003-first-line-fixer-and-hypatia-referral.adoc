= Architecture Decision Record: 0003-first-line-fixer-and-hypatia-referral

== 3. The squabbler is the first line; Hypatia is the referral

Date: 2026-11-13

== Status

Accepted (owner ruling, 2026-11-13). Implementation is staged; see
<<staging>>. This record amends the v0.1 scope row of `docs/CHARTER.adoc`
("Gate-deadlock class only, not red→green code fixes"). The "not a bypass" and

== Decision

=== Roles

[cols="1,3"]
|===
| cicd-squabbler
| First line, standalone, per repo. Diagnoses and fixes what it can fix
safely. It is the only party a repository user talks to. It still never
bypasses a gate.

| Hypatia
| Referral and final authority. Symbolic diagnosis first, neural assist
second. It answers with a Bustfile and may update squabbler rules after an
incident. Users never address it directly.

| Execution
| GitHub Actions runs from `.git-private-farm`; package updates through
`git-logistics-farm`; a rapidly spreading crisis through `.git-private-farm`
with the tsunami blocker. Hypatia does not do the work itself.

| gitbots
| Specialists that Hypatia instructs once a case is diagnosed. Squabblers and
local third-party apps or networks go first; gitbots take what the others
cannot or do not do, or break it into parts they can do.
|===

=== The squabbler's first-line contract

. *Fix only what is safe.* A first-line fix may change CI configuration or
  code (owner ruling 2026-11-13: "any safe code fix"), and the squabbler
  judges safety for each fix. A fix is never safe when it would remove or
  loosen a test assertion, skip or ignore a test, lower a threshold, drop a
  check, add a baseline or suppression entry, or edit code under a
  `bot_directives` restriction. Such a case is referred. Every fix must leave
  the gate's own checks passing on its head.
. *Refer when safety is at risk.* The squabbler tells the user, in this order:
  .. "Referred to Hypatia. Not done yet: wait for its answer." (or, when
     Hypatia is unreachable: "Hypatia is unreachable. This is a job for
     Hypatia; nothing was changed.");
  .. its own view of the problem;
  .. the solution, if it knows one;
  .. the risk it is trying to avert.
. *Override.* Only an admin can tell the squabbler to go ahead, after the
  warning above, and only with an authenticated confirmation (the owner's "password override/admin user only", confirmed by the
  owner on 2026-11-13 as admin AND authenticated). Codeowner status alone
  is not enough. The squabbler then says that it is overriding, that
  it warned against this, and records who overrode it. An override never
  turns into a gate bypass: the gate's own checks still decide green.
. *Dialogue.* With codeowner permission, a user can discuss a Bustfile, but
  only through the local squabbler, which relays to Hypatia.
. *Learning.* After an incident, Hypatia may update the squabbler's rules,
  also when the referral was right. The squabbler shares the update with
  squabblers in similar repositories through the coordination protocol.

=== Hypatia's Bustfile

A Bustfile is the Bust contractile (failure and breakage, not drift) written
for one referral. It carries: the detailed analysis; where the analysis got
stuck; where else in the estate the problem occurs; the source class (bad
coding, upstream, syntax error, a language limit such as type or memory
safety, wrong use of a deprecated or known-problem thing that needs a change
of practice, or other); and the fix, if one is known.

=== Directives

A gitbot acts on Hypatia's instruction unless the repository's `bot_directives`
say "do not touch", "do not look", or "do not change this code" (for example
a compliance module whose socio-technical nuances a bot cannot see). Then the
bot does not act, and it reports back with a `directive_override` message.

== What already exists

* `squabble_core::outcome::Escalation` with `ExpertGroup::Hypatia` and
  `ExpertGroup::HypatiaFleet` is the referral. `squabble-cli/src/boj.rs`
  routes it to a cartridge and already fails closed on an unreachable expert
  ("expert unreachable, escalation stands, fail-closed").
* The outcome contract (GREEN, YELLOW, RED with report) is the user-facing
  answer; ADR 0002 keeps a vacuous green from passing as a real one.
* `coordination.k9` is the squabbler's coordination binding.

== Consequences

=== Positive

* One user-facing voice per repository; Hypatia stays the authority.
* Most failures stop at the first line, which keeps load off Hypatia.

=== Negative

* The squabbler now carries fix logic, so each rule needs a test that shows
  it cannot weaken a check.

=== Neutral

* The squabbler stays usable without Hypatia: with Hypatia unreachable, it
  still fixes what is safe and refers the rest by saying so.
