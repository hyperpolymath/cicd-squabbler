= squabble-forge GraphQL documents

`github-schema.graphql`:: A verbatim snapshot of GitHub's public GraphQL
schema (`https://docs.github.com/public/fpt/schema.docs.graphql`), taken
2026-09-29, SHA-256
`20c6ccbd41870ed4e773a75f90ed26796eaf660b586d6f8f19c59b30f407cd15`. It is
GitHub's published schema, kept here only so tests can validate queries. It
is not estate-authored, so it carries no SPDX header, and it must not be
edited by hand or by any licence sweep.

`workflow_tree.graphql`:: The per-repo fragment for `squabble chains`. It
reads a repo's default-branch commit OID and its `.github/workflows` tree from
the *same* commit.

== Refreshing

`just graphql-schema-refresh` downloads the current schema, prints its hash,
and re-runs `cargo test -p squabble-forge`. If a field a query uses has
changed, `generated_query_validates_against_the_schema_snapshot` fails and
names it. Update the query, not the test.

The snapshot is about 1.5 MB. If that is unwelcome in the tree, the
alternative is to fetch it in CI before the test. That trades a
reproducible, reviewable diff for a network dependency in the test run.
