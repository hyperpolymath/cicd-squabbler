= squabble-creusot — the Creusot complement

The Rust twin of `spark/`: a parallel verification artefact that states the
engine's load-bearing invariants to a prover instead of only testing them.

**Status: stated, not proved.** No obligation has been discharged.

* `src/model.rs` — the invariants as ordinary Rust, plus `#[test]`s that compare
  them with the real `squabble-core`. Runs on **stable** Rust; no Creusot
  installation needed.
* `src/contracts.rs` — the same statements as `#[requires]`/`#[ensures]`
  contracts, compiled by default (`default = ["creusot"]`) so that a prove run
  cannot silently discharge an empty module; the stable half is built with
  `--no-default-features`.

[source,sh]
----
just verify-mirror     # stable: does the model still match the engine?
just verify-creusot    # the prover: do the obligations discharge?
----

Own workspace (see `Cargo.toml`), own `rust-toolchain.toml` pinning the nightly
that Creusot v0.14.0 is built against, and `publish = false`. It is deliberately
outside the root workspace so the stable `--locked` build never resolves
`creusot-std`.

`creusot-std = "0.14"` here, and the `creusot_version`/`rust_nightly` inputs in
`.github/workflows/creusot.yml`.
