= squabble-creusot — the Creusot complement

The Rust twin of `spark/`: a parallel verification artefact that states the
engine's load-bearing invariants to a prover instead of only testing them.

**Status: obligations discharged at the recorded merge checkout.**
https://github.com/hyperpolymath/cicd-squabbler/actions/runs/41909189438/job/126852164109[Hosted job 126852164109]
on 2026-11-04 rejected the false control, proved the true control, and reported
`Proved (13 files)` for this crate at
`f9499a8de0b8c525459a669e2cdbcacf83a49b85`. That is a file-level result, not a
theorem count. The gate's zero trusted-axiom field counts only tracked Rust
lines containing the literal `#[trusted]`; it does not count axioms from
dependencies or the prover. This is the merge of PR head
`1fd9db9bb94d9ac8ed54f7a6ef4f8c51ff35a848` into base
`17284299184fd31a10c7bf382f02262cd0ab308c`. The receipt covers these contracts
at that source, not later revisions or the full operational engine. The stable
mirror tests are a separate validation step.

* `src/model.rs` — the invariants as ordinary Rust, plus `#[test]`s that compare
  them with the real `squabble-core`. Runs on **stable** Rust; no Creusot
  installation needed.
* `src/contracts.rs` — the same statements as `#[requires]`/`#[ensures]`
  contracts, compiled by default (`default = ["creusot"]`) so that a prove run
  cannot silently discharge an empty module; the stable half is built with
  `--no-default-features`.

[source,sh]
----
just verify-mirror     # stable: does the model still match the engine?
just verify-creusot    # the prover: do the obligations discharge?
----
